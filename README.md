## Tugas 1 - Merancang UI Mobile

Aplikasi Android berbasis Kotlin & XML di Android Studio.

### 📱 Fitur & Komponen
* **Layar 1 (MainActivity)**: Beranda, Profil, Form Input.
* **Layar 2 (SecondActivity)**: Detail Portofolio & Skill Set.
* **Komponen**: LinearLayout, ScrollView, TextView, EditText, ImageView, Button, strings.xml, colors.xml.

### 🚀 Cara Menjalankan
* Build & Install: `./gradlew installDebug`
